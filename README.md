# 급식 이상형 월드컵

서울시교육청 AI교육센터 파일럿 프로그램 「급식 AI 문제해결(고등)」의 학생 10차시 동안 만드는 웹앱이 단계별로 어떻게 발전하는지 보여 주는 데모 페이지입니다.

- 페이지: https://greatsong.github.io/meal-worldcup/ (목차에서 학생 1~10차시, 교원 연수 1~10차시 페이지로 이동)
- 근거 자료: 급식_AI문제해결_고등 학생 01-10차시 검토본 v05, 교원 01-10차시 검토본 v04 (2026-11-03)
- 월드컵 후보, 별점 응답, 잔반률은 모두 수업용 가상값 또는 모의값입니다. 급식 메뉴만 NEIS 공개 API의 실제 응답입니다.
- 외부로 전송하는 기능은 없습니다. 기록은 사용하는 브라우저의 localStorage에만 저장됩니다.
